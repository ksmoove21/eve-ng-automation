# Active execution plans

Store one Markdown file per active substantial sprint in this directory.

A plan must follow [`.codex/PLANS.md`](../../../.codex/PLANS.md) and must be kept current enough that a new session can resume from it without reconstructing the sprint from chat.

If no substantial sprint is active in the public repository, this directory may contain only this README.

Do not fabricate public active state for work that exists only in a private workspace or an unpushed local branch.
